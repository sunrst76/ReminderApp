# 📅 Планировщик напоминаний (ReminderApp)
<img width="796" height="622" alt="image" src="https://github.com/user-attachments/assets/18b13fad-bc6e-4dc8-8814-64723cff5262" />
Десктопное приложение для создания, управления и гибкой настройки напоминаний, разработанное на C++ с использованием фреймворка Qt. Обладает глубокой интеграцией с системой Windows и внешними сервисами.

## ✨ Возможности (Features)
* 💾 **Надежное хранение данных**: полная локальная база данных **SQLite** для сохранения напоминаний. Данные автоматически записываются в системную папку `AppData`, благодаря чему они не теряются после закрытия приложения или перезагрузки ПК.
* 🔔 **Многоканальные уведомления**:
  * Всплывающие уведомления на рабочем столе.
  * Интеграция с системным Центром уведомлений Windows.
  * 💬 **Telegram-бот**: отправка напоминаний прямо в ваш мессенджер.
* 🗣️ **Голосовое воспроизведение**: озвучивание текста напоминания голосом.
* ⚙️ **Гибкое управление задачами**:
  * Быстрый перенос времени (+5 минут, +1 час, на завтра).
  * Настройка приоритетов (Низкий, Средний, Высокий) и категорий задач.
  * Установка периодичности (Однократно, Ежедневно и т.д.).
  * Редактирование, удаление и очистка выполненных записей.
* 🔍 **Поиск и фильтрация**: удобный поиск по тексту напоминаний и фильтрация по категориям/приоритетам.
* 📥 **Работа в фоновом режиме**: сворачивание приложения в системный трей (Tray Icon) для экономии места на экране.
* 🌗 **Современный интерфейс**: удобная темная тема, оптимизированная для комфортной работы.
* **Для получения уведомлений в Телеграмм-бот, укажите в файле config.ini свои данные: Токен бота и chatID!**

## 🛠️ Стек технологий (Tech Stack)

* **Язык**: C++ (C++17 / C++20)
* **Фреймворк**: Qt 6 / Qt 5 (Widgets)
* **База данных**: SQLite (модуль `Qt SQL` / `QSqlDatabase`)
* **Платформа**: Windows

## 🚀 Как запустить проект локально (Getting Started)

### Требования
* Установленный **Qt SDK** (включая Qt Widgets).
* Компилятор (MSVC или MinGW) и **CMake** / **Qmake**.

### Сборка и запуск (CMake)
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/sunrst76/ReminderApp.git
   ```
2. Перейдите в папку проекта:
   ```bash
   cd ReminderApp
   ```
3. Создайте папку для сборки и соберите проект:
   ```bash
   mkdir build && cd build
   cmake ..
   cmake --build .
   ```
4. Запустите исполняемый файл из папки `build`.
5. **Для получения уведомлений в Телеграмм-бот, укажите в файле config.ini свои данные: Токен бота и chatID!**
